# Реклама MeloDesk с твоего компьютера

На рабочем столе есть ярлык «Реклама MeloDesk». Он запускает раздачу в фоне и открывает локальную панель. Меняй заголовок, описание, изображение и ссылки на канал/бота, затем нажимай «Сохранить и обновить баннер». Обновление у клиентов занимает примерно 15 секунд. PNG/JPEG/WebP до 2 МБ; без картинки используется голубое оформление MeloDesk.

Анонс MeloDeskNews уже включён. Пока канал и бот не созданы, кнопки подписаны «Скоро» и не ведут на чужие страницы. После создания укажи настоящие ссылки https://t.me/..., измени подписи кнопок и отключи режим «Канал и бот скоро появятся».

Объявление показывается вверху страницы «Моя волна», перед основным содержимым, над нижним плеером. Пользовательской кнопки закрытия нет; владелец управляет показом из панели. Официальная реклама Telegram не заменяется.

Временный HTTPS-адрес обеспечивает Cloudflare Quick Tunnel. Он работает, пока запущена программа и компьютер подключён к интернету. После перезапуска туннеля адрес может измениться. Для постоянного адреса потребуется собственный домен и постоянный туннель. Пересборка клиента для изменения текста/картинки не нужна; для изменения адреса раздачи заменяется файл promotions.json рядом с Telegram.exe. Панель умеет скачать этот файл.

Панель управления: только 127.0.0.1:18741 с личным ключом, который хранится локально. Публичный origin 127.0.0.1:18740 выдаёт только /v1/banner и /assets/<hash>. Через туннель порт управления не публикуется. Не передавай ярлык/адрес с личным ключом другим людям. Никакие переписки, аккаунты, музыка или плейлисты в раздачу не включены.

Установленные файлы: %LOCALAPPDATA%/Programs/MusiGramAds. Настройки и баннеры: %LOCALAPPDATA%/MusiGramAds. Исходники здесь не содержат личного ключа. Python 3.10.11 и cloudflared 2026.10.5 установлены отдельно для владельца ПК; они не нужны пользователям клиентской сборки.
